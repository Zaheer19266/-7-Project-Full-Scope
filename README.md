# -7-Project-Full-Scope
🌿 LiveItClean

LiveItClean is a sustainability-focused web platform designed to inspire eco-friendly living.
It empowers users to:
•	🌱 Explore an Eco Marketplace for sustainable products.
•	📊 Track their carbon footprint with a Sustainability Tracker.
•	🤝 Engage with others through a Community Forum for green living discussions.
Built with Vite + JavaScript, LiveItClean provides a fast, modern, and interactive experience.
Step to Run the Code:
🧰 1. Prerequisites
Make sure you have the following installed:
•	Node.js (preferably version 18 or newer)
•	npm (comes with Node.js)
To verify, open a terminal and run:
node -v
npm -v
If you don’t have Node.js, download it from nodejs.org.

📦 2. Install Dependencies
Navigate to your project folder in the terminal:
cd path/to/your/project
Then install dependencies using:
npm install
This command reads your package.json and installs all required packages into the node_modules folder.

🚀 3. Start the Development Server
Once installation is complete, start the local development server:
npm run dev
By default, Vite will start a local server (usually at http://localhost:5173).
